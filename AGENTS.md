# AGENTS.md

Этот репозиторий — source of truth для управления Mac Сергея из обычного ChatGPT-чата.

## Главный принцип

Не проси пользователя повторять уже пройденную настройку.
Перед работой прочитай этот файл, затем `state/current.md` и релевантный runbook из `docs/`.

Рабочий канал по умолчанию: обычный чат ChatGPT + Remote Desktop Commander.
Не переключай задачу в Codex/Work только потому, что они доступны.
Если пользователь прямо не попросил иначе, продолжай именно в текущем обычном чате.

## Режим работы

1. Сначала инспектируй текущее состояние Mac и проекта инструментами.
2. Затем выполняй действия сам; не выдавай инструкции пользователю вместо выполнения.
3. Для GUI используй AppleScript/System Events, `mactl`, `cliclick` и скриншоты.
4. После GUI-действий проверяй результат скриншотом или доступным состоянием приложения.
5. Для кода и файлов предпочитай терминал/CLI: это быстрее и надёжнее GUI.
6. Для GitHub используй существующую SSH-авторизацию `IMONsergey`.
7. Для публичных изменений проекта — тест/проверка перед публикацией.
8. Не уничтожай данные и не делай необратимые действия без явной необходимости.

## Двухчатовый режим

Каноническая схема:
- Chat A — текущий пользовательский чат, Orchestrator / Executor. Он имеет Desktop Commander, реально меняет Mac/проекты и проверяет результат.
- Chat B — отдельный обычный ChatGPT-чат, Planner / Reviewer. Он получает компактные факты, критикует решение и выдаёт следующий шаг или verdict.

Chat A синхронно обращается к Chat B через локальный reviewer bridge, получает ответ в tool output и продолжает выполнение в том же turn. Не нужно отправлять сообщения обратно в Chat A через браузер.

Цикл продолжается до критериев готовности или лимита итераций.

Никогда не запускай бесконечный ping-pong.
По умолчанию максимум 8 итераций на одну задачу.
После 8 итераций остановись, суммируй блокеры и запроси решение только если без пользователя нельзя продолжить.

Не передавай между чатами секреты, токены, пароли и содержимое keychain.
Не копируй в другой чат больше контекста, чем нужно для текущего шага.
Подробности: `docs/PING_PONG.md`.

## Голос

Пользователь хочет говорить в этот же обычный чат.
Предпочтительный путь: macOS Dictation -> текст в composer ChatGPT -> обычная отправка.
Не подменяй это отдельным Voice/Codex-режимом без запроса.
Подробности: `docs/VOICE.md`.

## GUI

Проверено: `System Events` видит приложения и frontmost process.
Проверено: `screencapture` создаёт полноценный снимок экрана.
Проверено: `cliclick` может читать позицию и двигать курсор.
Проверено: `mactl` установлен в `~/.local/bin/mactl`.

## Статусы

В документации используются только три статуса:
- `VERIFIED` — реально проверено на этом Mac.
- `PARTIAL` — часть цепочки работает, но end-to-end не завершён.
- `PLANNED` — решение описано, но не проверено.

Не повышай статус без фактической проверки.

## Приоритет инструментов

Для файлов/кода: Desktop Commander filesystem/process tools -> CLI -> GUI.
Для браузера: сначала адресные средства браузера/AppleScript, затем Accessibility, затем координатный клик.
Для текста между приложениями: clipboard (`pbcopy`/`pbpaste`) предпочтительнее посимвольного ввода.
Для поиска по репозиториям: `rg`/`fd`.
Для JSON/YAML: `jq`/`yq`.
Для снимка состояния: команды + screenshot.

## После новых улучшений

Если ты добавил новый рабочий способ, исправил проблему или обнаружил ограничение:
1. обнови `state/current.md`;
2. обнови соответствующий файл в `docs/`;
3. при необходимости обнови `scripts/`;
4. закоммить и отправь изменения в `main`;
5. в ответе пользователю укажи, что knowledge base обновлена.
