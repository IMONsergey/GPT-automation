# Voice -> ordinary ChatGPT chat

## Требование пользователя

Голос должен попадать именно в тот же обычный ChatGPT-чат, где доступны текущие инструменты и Desktop Commander.
Не переводить пользователя в Codex только ради голоса.

## Рабочее решение

Статус: `VERIFIED` для системной диктовки, `PLANNED` для полного one-hotkey UX.

macOS Dictation уже включена.
Нужная цепочка:
1. активировать вкладку/окно текущего ChatGPT-чата;
2. сфокусировать composer;
3. включить Dictation;
4. речь преобразуется в обычный текст;
5. отправить сообщение;
6. текущий чат выполняет его через Desktop Commander.

Плюс этого пути: голос — только способ ввода. Сам чат и tool context не меняются.

## Почему не делать постоянно слушающий Voice Control по умолчанию

Постоянный Voice Control может перехватывать команды во всех приложениях и мешать обычной работе.
Default UX должен быть push-to-talk / Dictation.
Wake phrase можно добавить позже отдельным opt-in слоем.

## Правило для агентов

Если пользователь говорит «голосом управляй ПК», сначала сохраняй текущий обычный чат.
Не создавай отдельный Codex/Work task без явного запроса.
Если продуктовая поддержка Voice/tool calling изменилась, сначала проверь фактически, а не исходи из старого предположения.

## План быстрого запуска

Наиболее устойчивый вариант: глобальная shortcut/Hotkey -> Chrome/ChatGPT tab -> focus composer -> Dictation.
Реализацию shortcut считать готовой только после реального теста: команда голосом должна стать сообщением именно в нужном чате и дойти до него без ручного клика.
